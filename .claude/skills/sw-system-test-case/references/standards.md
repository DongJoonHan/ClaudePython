# 표준 요건 요약 (A-SPICE / ISO 26262-6)

테스트 케이스 설계와 산출물이 어떤 표준 요건을 근거로 하는지 정리한 문서입니다. 사용자가 감사·심사 대응 근거를 물을 때, 또는 산출물이 아래 요건을 모두 충족하는지 최종 점검할 때 읽으세요.
표 번호와 BP 번호는 표준 판(edition)에 따라 다릅니다. 고객이나 조직이 판을 지정했다면 그 판을 따르고, 보고서에는 기준 판을 적으세요.

## Automotive SPICE — SW 시스템 테스트(SW 적격성 시험)

| 판 | 프로세스 | 관련 BP |
|---|---|---|
| v3.1 | SWE.6 Software Qualification Test | BP1 테스트 전략(회귀 포함), BP2 테스트 명세 개발, BP3 테스트 케이스 선정, BP4 통합 SW 테스트, BP5 양방향 추적성 확립, BP6 일관성 보장, BP7 결과 요약·전달 |
| v4.0 | SWE.6 Software Verification | BP1 검증 조치 명세, BP2 검증 조치 선정, BP3 통합 SW 검증, BP4 일관성 보장 및 양방향 추적성 확립, BP5 결과 요약·전달 |

이 스킬의 산출물이 충족해야 하는 점:
- **테스트 명세 (v3.1 BP2 / v4.0 BP1):** 케이스마다 목적, 사전 조건, 입력, 절차, 예상 결과(합격/불합격 판정 기준)가 있어야 합니다. 테스트 기법과 테스트 환경도 명시합니다.
- **양방향 추적성 (v3.1 BP5 / v4.0 BP4):** SW 요구사항 → 테스트 케이스(추적성 매트릭스 시트)와 테스트 케이스 → SW 요구사항(각 TC의 베이시스 ID 열)이 모두 성립해야 합니다.
- **일관성 (v3.1 BP6 / v4.0 BP4):** 케이스 내용이 참조한 요구사항의 내용과 실제로 일치해야 합니다. ID만 연결해 두고 내용은 다른 것을 검사하면 일관성 위반입니다.
- **선정 근거 (v3.1 BP3 / v4.0 BP2):** 어떤 기법으로 왜 이 케이스를 골랐는지가 기법 열과 커버리지 요약에 드러나야 합니다.

## ISO 26262-6:2018 — Clause 11 "Testing of the embedded software"

- **목적:** 임베디드 SW가 목표 환경에서 SW 안전 요구사항을 만족함을 입증합니다.
- **Table 13 – 테스트 환경:** HIL(Hardware-in-the-loop), ECU 네트워크 환경, 차량. ASIL이 높을수록 실제 목표 HW에 가까운 환경을 강하게 권장합니다. 그래서 각 TC에 **테스트 환경**을 적습니다.
- **Table 14 – 테스트 방법:** 요구사항 기반 테스트(모든 ASIL에 ++), 폴트 주입 테스트(ASIL C/D에 ++, A/B에 +). 안전 메커니즘을 요구하는 항목에는 폴트 주입 케이스를 검토합니다.
- **Table 15 – 테스트 케이스 도출 방법:**
  1a 요구사항 분석 (모든 ASIL에 ++)
  1b 동치 클래스 생성·분석 (A: +, B~D: ++)
  1c 경계값 분석 (A: +, B~D: ++)
  1d 경험·지식 기반 오류 추측 (A/B: +, C/D: ++)
  1e 기능 의존성 분석
  1f 운용 사용 사례(operational use case) 분석
- **완료 기준:** 요구사항 커버리지를 측정합니다. 모든 SW 안전 요구사항이 최소 한 개의 테스트로 검증돼야 합니다.

이 스킬의 기법 매핑:
- 동치 분할 → 1b
- 경계값 분석 → 1c
- 페어와이즈(PICT) → 1e (파라미터 간 기능 의존성·상호작용)
- WoW 검증 → 1d, 1f (경험 기반 엣지 상황, 실사용 시나리오의 극단 조건)
- 폴트 주입 → Table 14 (1b)

## 최종 점검표

- [ ] 모든 베이시스 항목에 TC가 하나 이상 있음 (커버리지 100%)
- [ ] 모든 TC가 존재하는 베이시스 ID를 하나 이상 참조함 (역방향 추적성 100%)
- [ ] TC 내용이 참조한 요구사항과 일치함 (일관성)
- [ ] 모든 TC에 판정 가능한 예상 결과가 있음 (값, 허용오차, 시간 조건)
- [ ] 테스트 환경이 명시돼 있고 ASIL에 맞음
- [ ] ASIL C/D 안전 메커니즘에 폴트 주입을 검토했음
- [ ] 결정하지 못한 사항은 "가정 및 질의" 시트에 기록돼 있음
