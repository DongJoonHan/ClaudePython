## 1. 통합 전략

- **통합 순서:** 아래에서 위로 통합한다. 3단계에서 C1~C5는 단위로, C6은 C1~C5를 실제로 연결한 상태로 시험했다. 이 단계는 그 위에서 두 가지를 검증한다.
  1. **시간 축 통합:** C1→C2→C3→C4→C6→C5 전체 경로를 10 ms 틱으로 여러 주기에 걸쳐 실행한다. Use Case 시나리오가 대상이다.
  2. **외부 인터페이스 통합:** C7(HTTP)부터 C6·C5까지의 JSON 경로
- **하네스:** `Drive` 클래스가 차량 입력 상태를 유지하며 틱을 진행한다. 시각은 정수 틱 번호 n으로 관리하고 `now_s = timestamp_s = n/100`이다.
- **목(mock):** 쓰지 않는다. 모든 구성요소는 실제 구현이다.
- **판정:** 출력(`Output`), `/api/status`, `/api/events`의 값으로만 판정한다(DR-18).

## 4. 발견 사항

| ID | 내용 | 분류 | 조치 |
|---|---|---|---|
| IN-01 | IT-04의 래치 해제 시점을 한 틱 일찍 기대함. 시동 OFF를 처음 관측한 틱이 경과 0 s이므로, 101번째 틱이 1.00 s다 | 시험 결함 | 시험 수정. 제품은 SWR-007대로 동작 |
| IN-02 | IT-08b 초안이 "timestamp 5.0 뒤의 과거 timestamp"를 정상으로 기대함 | 시험 결함 | 고착 timestamp와 역순 프레임 시험으로 나누어 다시 작성 |

제품 결함은 발견되지 않았다.

## 5. 결론

SWA-ECL-001의 구성요소 간 인터페이스 7개와 Use Case 10개 중 UC-01~UC-09를 통합 수준에서 검증했다. UC-10(결정론 1,000회 재생)은 SWE.6 SIL 시험에서 다룬다. 기준선 BL-INT-1.0으로 확정할 수 있다.
