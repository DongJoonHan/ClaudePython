| 항목 | 내용 |
|---|---|

## 4. 커버리지 요약

| 항목 | 결과 |
|---|---|
| OEM 요구 13건 중 SWR로 추적된 건수 | 13건 (100%) |
| SWR 21건 중 OEM 요구로 역추적된 건수 | 21건 (100%) |
| OEM 인터페이스 9건(필드 20개) 중 SWRS에 정의되고 SWR이 사용하는 건수 | 9건 (100%). gear는 형식 검사만 하고 판정에는 쓰지 않는다 |
| OEM 9장 계획과의 차이 | SWR-019 추가(Q-14). 1장 "추가 연결" 열의 연결 추가 |

2단계 이후 테스트 케이스가 생기면 "SWR → 테스트" 열을 추가해 이 표를 갱신한다.
