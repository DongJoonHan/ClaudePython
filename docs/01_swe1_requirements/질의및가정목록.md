| 항목 | 내용 |
|---|---|
| 문서 ID | QA-ECL-001 |
| 버전 | 1.0 (BL-SWR-1.0 후보) |
| 관련 문서 | SWRS-ECL-001 SW 요구사항 사양서, OEM-SWR-001 Rev 1.0, RVW-ECL-001 검토 기록 |
| 처리 원칙 | 개발 계획서 D-06에 따라 안전을 우선하는 잠정 가정으로 진행하고, 각 가정은 OEM-A 질의로 확인한다 |

## 1. 잠정 가정 수립 원칙

1. **ASIL 우선:** ASIL B 요구의 동작은 QM 요구나 QM 신호가 뒤집지 못한다. QM 로직이 안전 요구의 무결성을 깨지 않게 하기 위해서다.
2. **ASIL B 안에서는 탑승자 탈출을 우선:** 충돌 긴급 해제(SR-001)는 OEM 문서에 "다른 명령보다 우선"으로 명시돼 있다. 그다음은 하차 시 충돌 위험(SR-002)이다.
3. **QM 안에서는 비상 탈출만 우선:**
   - 화재·과온 강제 해제는 비상 탈출이므로 ISOFIX 잠금과 자동 잠금보다 우선한다.
   - 성인 탑승 해제는 비상 상황이 아니므로, 어린이 보호(ISOFIX)와 주행 중 잠금보다 낮게 둔다.
4. **정의가 없는 값:** 수용 기준을 판정할 수 있게 하는 가장 보수적인 값을 고른다.

## 3. 가정이 바뀔 때의 처리

- 각 가정은 2단계 이후 테스트 케이스로 고정한다. OEM 회신으로 가정이 바뀌면 해당 테스트가 실패하므로 영향 범위가 바로 드러난다.
- 회신 결과는 이 문서와 SWRS-ECL-001의 해당 요구를 개정해 반영하고, 새 기준선을 만든다(예: `BL-SWR-1.1`).
