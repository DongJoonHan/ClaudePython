# 검토 기록: SWE.1 SW 요구사항

| 항목 | 내용 |
|---|---|
| 문서 ID | RVW-ECL-001 |
| 검토 대상 | SWRS-ECL-001, QA-ECL-001, UC-ECL-001, TRC-ECL-001 (모두 v1.0 후보) |
| 기준 문서 | OEM-SWR-001 Rev 1.0 |
| 검토 방식 | 독립 검토. 작성자의 문맥 없이 시작한 별도 AI 에이전트가 OEM 원문과 대조했다 |
| 검토 관점 | 완전성, 정합성, 검증 가능성, 안전(QM이 ASIL B를 뒤집는지), 추적성 |
| 한계 | 사람 검토자의 서명 검토가 아니다. G1 수용(OEM-A SW Requirements Owner)과 사내 기술 검토 서명은 별도로 필요하다 |

## 1. 검토 이력

| 회차 | 대상 버전 | 결과 |
|---|---|---|
| 1차 | 0.1 초안 | 지적 20건 (주요 6, 보통 7, 경미 7). 기준선 불가 |
| 2차 | 1.0 개정 1 | RV-01~20 모두 해소. 개정으로 새로 생긴 결함 3건 (주요 2, 보통 1) |
| 3차 | 1.0 개정 2 | RV-21~23 해소, 새 주요 결함 없음. **BL-SWR-1.0 기준선 가능** 판정 |

## 3. 결론

- 1차 검토의 20건과 개정 중 생긴 5건(RV-21~25)을 모두 조치했다.
- 3차 확인에서 "새 주요 결함 없음, BL-SWR-1.0 기준선 가능" 판정을 받았다. RV-24·25는 이 판정의 권고 사항으로, 반영 후에는 다시 검토하지 않았다.
- 미결 OEM 질의 Q-01~Q-21은 문서화된 잠정 가정으로 진행한다. G1에서 OEM-A에 질의 목록을 전달한다.
- **남은 승인 절차:** 사내 기술 검토 서명과 OEM-A G1 수용은 사람이 수행해야 한다.
