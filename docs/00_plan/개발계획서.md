# 개발 계획서: 전자식 차일드락 제어 SW

| 항목 | 내용 |
|---|---|
| 문서 ID | PLAN-ECL-001 |
| 버전 | 1.0 (0단계 완료 시점) |
| 입력 문서 | OEM-SWR-001 OEM SW 요구사항 사양서 Rev 1.0 (BL-OEM-1.0) |
| 관련 프로세스 | A-SPICE MAN.3 (프로젝트 관리), SUP.8 (형상관리) |

## 1. 목적과 범위

OEM-A가 할당한 전자식 차일드락 제어 SW를 Python 3.12 PC/SIL 참조 구현과 Web 시뮬레이터로 개발한다. 후석 좌/우 잠금 판단, 상태, 이벤트 생성까지가 공급자 책임이다.

범위 밖: HIL, 실차, 타깃 ECU, 도어 래치·구동기 HW, HARA·ASIL 도출, 인증
